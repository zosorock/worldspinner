# US-004: Display Discovery Card Rewards

**Status**: Done
**Priority**: Critical - Day 1

## User Story

As a player
I want to see an educational discovery card after guessing
So that I can learn interesting facts about the country

## Acceptance Criteria

- [x] Discovery card appears after guess (whether correct or incorrect)
- [x] Shows country name and flag
- [x] Displays 2-3 simple, fun facts about the country
- [x] Facts are age-appropriate for 7-12 year olds
- [x] "Play Again" button returns to spin screen
- [x] Card is visually distinct from game screen (can use simple border/background color)

## Technical Notes

- Facts hardcoded in code with country data
- No need for elaborate card animations on Day 1
- Focus on readability and clear presentation
